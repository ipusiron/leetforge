リート（1337 Speak）とは

リート（leet）は、英数字や記号を使って文字を置き換える表記法です。「elite（エリート）」が元で、leet・l33t・1337・31337とも書かれます。

このツールの変換は、どの文字をどの記号に置き換えるかを決めた対応表を機械的に当てるだけです。文脈は見ません。

1980年代

BBS（電子掲示板）の「elite」

隠し区画に入れる利用者をeliteと呼び、その綴りを崩したl337や31337が使われた。検索やフィルターに引っかからないよう綴りを崩したのが始まりとされる。

1998年

31337が広く知られる

DEF CON 6で公開された遠隔操作ツールBack Orificeが、既定のポートに31337を使った。

2000年代

インターネット文化に定着

オンラインゲームやチャットでpwned・n00bなどの語とともに広まり、ミームとして定着した。

基本的な変換ルール

形状による置換

A → 4, @ 三角形の類似性
E → 3 横向きの形状
I → 1, ! 縦線の形状
O → 0 円形の類似性
S → 5, $ 曲線の形状
T → 7, + 十字形の構造

複合文字による表現

H → |-|, # 横棒で連結
M → /\/\ ジグザグ形状
W → \/\/ V字の連続

同じ記号を複数の文字が使う（1はiとl、7はtとl、| はi・l・t）ので、リートは一意には元に戻せません。

活用場面

🎮

遊び・名前

  • ゲームやSNSのユーザー名、配信のテロップ、Tシャツの文字
  • 謎解きや脱出ゲームの問題文、TRPGのハッカー役の台詞
  • CTFの解説記事や海外の掲示板に出てくる1337表記を読む
📚

教育

  • 置換暗号のいちばん簡単な例として、対応表と変換の関係を体験する
  • 「ルールが公開されていれば、見た目が変わっても候補は数えられる」を実感する
  • プログラミングの文字列操作の練習題材
🔒

セキュリティ

  • リートはパスワードを強くしません。hashcat・John the Ripper・cuppの辞書攻撃には同じ置換の表が入っています（マッピングタブの「攻撃ツールの表」で確かめられます）
  • NIST SP 800-63B-4（2025年）は、サービス側に「文字種の組み合わせなどの構成規則を課してはならない」と求め、長さと漏えい済みリストの照合を重視しています
  • NGワードのフィルターを試験する入力（v1agraのような回避例）を作る

注意点とベストプラクティス

⚠️ 注意点

  • 可読性の低下: 置き換えが増えるほど読めなくなる
  • アクセシビリティ: 読み上げソフトは記号を文字として読めない
  • 強度の錯覚: 2016年の研究（Urら、CHI’16）では、参加者はp@ssw0rdをpAsswOrdより強いと感じたが、推測に要する回数はpAsswOrdのほうが約4,000倍多かった
  • 一意に戻らない: 1→i/l、0→o、5→sのように逆変換は候補の列挙にしかならない

✅ 効果的な使い方

  • 段階的な変換: 変換率を下げるか、基本プリセットから始める
  • 一貫性: シードを固定すれば同じ入力は同じ結果になる
  • 用途に合わせる: 名前や短い語ならASCIIのみ、遊びなら非ASCIIの記号も
  • パスワードには使わない: 長いパスフレーズとパスワードマネージャーを

対応表（マッピング）

有効 キー/単語 候補 操作
キーは1文字または単語。1文字は大文字・小文字を区別し、単語は区別せず語の単位で当たります。単語が文字より優先されます。
